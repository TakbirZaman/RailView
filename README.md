RailView – OpenGL Railway Simulation

A 2D computer graphics project developed in C++ using the OpenGL (GLUT) library.
This simulation showcases a beautifully animated railway station featuring trains, environmental elements, and an interactive Day/Night cycle. 
All visual elements are created using raw OpenGL primitives, representing classical graphics programming techniques.

🎮 Controls
Key	Action
D	Switch to Day Mode
N	Switch to Night Mode
Esc	Exit the simulation
S	Stop all train movement
R	Resume train movement
+	Increase train speed
-	Decrease train speed
C	Increase cloud speed
M	Toggle moon movement on/off
L	Turn lamps ON/OFF
1	Show only Train 1
2	Show only Train 2
A	Change background color dynamically
